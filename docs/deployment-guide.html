Seed Redis
Populate live data so panels aren't empty
▼
Pull production env vars locally
terminal 
vercel env pull .env.vercel.local
Run seed scripts
macOS / linux 
source .env.vercel.local
./scripts/run-seeders.sh
windows powershell 
# Load env vars
Get-Content .env.vercel.local | ForEach-Object {
  if ($_ -match '^([^#=][^=]*)=(.+)$') {
    [System.Environment]::SetEnvironmentVariable($matches[1], $matches[2])
  }
}
# Run seeders individually
node scripts/seed-earthquakes.mjs
node scripts/seed-weather.mjs
node scripts/seed-conflicts.mjs
node scripts/seed-crypto.mjs
Each seeder prints: ✓ Seeded X records → Redis key: <key>

expected

troubleshooting
502 → ANTHROPIC_API_KEY missing or invalid in Vercel env
429 → rate limit hit, wait 1 hour
500 → check Vercel build logs for errors
Browser checklist
Open https://YOUR_APP.vercel.app and verify:

✅ Dashboard loads, map visible
✅ At least one data panel shows content (earthquakes, crypto, etc.)
✅ Foresight panel visible → click it → type a subject
✅ Analysis runs in 8-15 seconds → MICMAC plot + variable list appear
✅ Reload page → Foresight subject still there (localStorage persistence)
Check the browser DevTools → Network tab. You should see POST /api/foresight-analyze returning 200. No direct calls to api.anthropic.com.
